회의를 녹음하고, 이 PC에서 전사·요약한 뒤, 검토한 요약을 내 이름으로 Slack 채널에 보내는 앱의 첫 정식 버전입니다.

## 설치 파일

| 컴퓨터 | 파일 |
|---|---|
| Mac (Apple 실리콘: M1 이후, macOS 14.6 이상) | `meeting-summarizer_1.0.0_aarch64.dmg` |
| Windows 10/11 (64비트) | `meeting-summarizer_1.0.0_x64-setup.exe` |

설치와 첫 실행은 [설치 안내](https://github.com/sijecorp/meeting-summarizer/blob/master/docs/install.md)를 따릅니다.

- Mac: Apple 검사를 받지 않은 사내 앱이라 처음 열 때 시스템 설정 > 개인정보 보호 및 보안에서 "그래도 열기"를 한 번 눌러야 합니다.
- Windows: "Windows의 PC 보호" 창이 뜨면 "추가 정보" > "실행"을 누릅니다.
- 처음 쓸 때 전사·요약 모델(약 3.4 GB)을 받습니다. 빈 공간이 약 4.4 GB 필요합니다.

## 1.0에 들어간 것

- **녹음**: 마이크와 시스템 오디오(화상 회의 상대방)를 함께 녹음합니다. 최대 4시간, 절전과 장치 바뀜을 견딥니다.
- **녹음 파일 가져오기**: mp3, m4a, mp4, wav, aac, flac, ogg 파일을 버튼으로 고르거나 창에 끌어다 놓습니다. 가져오는 동안 아래 독에 진행률이 보입니다.
- **이 PC에서 전사와 요약**: 회의 내용이 PC 밖으로 나가지 않습니다(Whisper large-v3-turbo, Qwen3-4B-Instruct-2507). 원하면 클라우드나 Ollama 같은 연결을 더할 수 있습니다.
- **검토**: 요약을 문서처럼 읽고 고칩니다. 담당자·기한이 없는 항목은 "미정"으로 표시합니다.
- **Slack 보내기**: 설정 > Slack에서 회사 Slack에 로그인하고, 회의마다 내가 들어가 있는 채널을 골라 내 이름으로 보냅니다. 웹훅 주소를 넣을 필요가 없습니다.
- **앱 창**: 1040×720 창, 앱 모양의 제목 막대(Mac은 신호등 버튼을 그대로, Windows는 앱이 그린 최소화·최대화·닫기).

## 알려진 제한

- Windows 설치 파일은 빌드 검사(테스트, CPU 명령어, 함께 든 파일)를 통과했지만 아직 실제 PC에 설치해 보지 않았습니다. 문제가 생기면 설정 > 일반 > "로그 폴더 열기"의 app.log를 보내 주세요.
- Intel 칩 Mac은 지원하지 않습니다.
- 앱에서 Slack을 30일 동안 쓰지 않으면 Slack 로그인이 끝납니다. 그때는 설정 > Slack에서 다시 로그인합니다.
