회의를 멈췄다 이어서 처리하고, 한국어 말고 영어·베트남어·인도네시아어 회의도 다루고, 요약을 여러 채널에 보내고, 녹음을 파일로 저장하는 버전입니다.

## 설치 파일

| 컴퓨터 | 파일 |
|---|---|
| Mac (Apple 실리콘: M1 이후, macOS 14.6 이상) | `meeting-summarizer_1.1.0_aarch64.dmg` |
| Windows 10(1809 이상)/11 (64비트) | `meeting-summarizer_1.1.0_x64-setup.exe` |

설치와 업데이트는 [설치 안내](https://github.com/sijecorp/meeting-summarizer/blob/master/docs/install.md)를 따릅니다. 이미 앞 버전을 쓰고 있으면 새 파일로 덮어 설치하면 되고, 회의 기록·설정·Slack 로그인은 그대로 남습니다. Mac은 새 버전도 처음 열 때 "그래도 열기"를 한 번 더 하고, 처음 Slack으로 보낼 때 키체인 접근을 물으면 Mac 로그인 암호를 넣고 "항상 허용"을 누릅니다.

## 되돌리기 전에 읽어 주세요

이전 버전에서는 일시정지·다른 언어·여러 채널 회의가 읽기 전용으로 보입니다. 이 셋을 쓴 회의만 그렇고, 쓰지 않은 회의는 이전 버전에서도 그대로 쓸 수 있습니다. 1.1.0으로 다시 올리면 모두 다시 열립니다.

## 바뀐 것

- **일시정지와 이어서 처리**: 회의 문서에서 처리 중이거나 대기 중인 회의를 "일시정지"하고, 나중에 "이어서 처리"합니다. 앱을 다시 켜도 멈춘 채로 있습니다. 전사는 끝난 구간부터, 요약은 끝난 부분부터 이어 갑니다. 멈춘 회의가 둘 이상이면 홈에서 "모두 이어서 처리"를 누릅니다.
- **전사 언어**: 회의마다 한국어·영어·베트남어·인도네시아어 중 하나 이상을 고릅니다. 기본 언어는 설정 > 전사에서 정하고, 녹음 화면과 파일을 가져올 때도 고를 수 있습니다. 언어를 둘 이상 고르면 말하는 조각마다 언어를 가려 그 언어로 전사합니다. 이때 언어 판별 모델(`ggml-tiny.bin`, 약 78MB)이 한 번 필요하고, 처음 두 번째 언어를 고를 때 배경에서 받습니다. 요약은 어느 언어의 회의든 한국어로 씁니다.
- **다른 언어로 다시 전사**: 언어를 잘못 골랐으면 회의 문서의 더보기 > "전사 언어 바꾸기"에서 다시 전사합니다. 전사본과 요약, 검토에서 고친 내용이 지워지므로 한 번 확인을 받습니다. 보낸 회의는 바꿀 수 없습니다.
- **LLM 연결로 다시 요약**: 이 PC가 요약한 베트남어·인도네시아어 회의는 검토 화면에 "요약이 실제 회의와 다른가요?"가 보이고, 저장한 LLM 연결을 골라 다시 요약합니다. 지금 요약과 검토에서 고친 내용은 지워집니다. 연결이 없으면 "LLM 연결 만들기"로 설정에 갑니다.
- **여러 채널 전송**: 이미 보낸 요약을 다른 채널로 또 보낼 수 있고, 보낸 채널이 모두 남습니다. 보낸 요약은 고칠 수 없어서 모든 채널에 같은 글이 갑니다.
- **녹음 파일 저장**: 더보기 > "녹음 파일 저장"으로 마이크와 시스템 소리를 합친 WAV 파일을 저장합니다. 요약이 없는 회의와 가져온 회의도 됩니다.

## 알려진 제한

- 베트남어·인도네시아어가 든 회의는 이 PC 요약이 숫자·통화·이름을 자주 틀리고 낱말을 엉뚱하게 옮기기도 하며, 베트남어 이름이 든 할 일은 담당자가 "미정"으로 나오기 쉽습니다. 설정 > 요약(LLM)에서 LLM 연결을 만들어 다시 요약해 볼 수 있습니다(이 경로의 품질은 아직 재지 않았습니다). 언어를 고를 때와 검토 화면에서 이 안내가 보입니다. 베트남어·인도네시아어는 실제 회의 녹음 대신 합성 회의로 확인했습니다.
- 한국어가 아닌 언어가 든 회의는 요약의 날짜를 확인하지 않습니다. 검토 화면에 "이 회의의 날짜는 확인하지 않았습니다"가 보입니다.
- 언어를 여러 개 고르면 전사가 더 걸립니다.
- Windows 설치 파일은 아직 실제 PC에 설치해 보지 않았습니다.
