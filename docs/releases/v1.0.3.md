Windows에서 전사가 느리던 문제를 줄이고, 느릴 때 그 이유와 기록을 남기는 버전입니다.

## 설치 파일

| 컴퓨터 | 파일 |
|---|---|
| Mac (Apple 실리콘: M1 이후, macOS 14.6 이상) | `meeting-summarizer_1.0.3_aarch64.dmg` |
| Windows 10(1809 이상)/11 (64비트) | `meeting-summarizer_1.0.3_x64-setup.exe` |

설치와 업데이트는 [설치 안내](https://github.com/sijecorp/meeting-summarizer/blob/master/docs/install.md)를 따릅니다. 이미 앞 버전을 쓰고 있으면 새 파일로 덮어 설치하면 되고, 회의 기록·설정·Slack 로그인은 그대로 남습니다. Mac은 새 버전도 처음 열 때 "그래도 열기"를 한 번 더 하고, 처음 Slack으로 보낼 때 키체인 접근을 물으면 Mac 로그인 암호를 넣고 "항상 허용"을 누릅니다.

## 느렸던 분께 부탁드립니다

1. 위 설치 파일로 1.0.3을 설치합니다.
2. 전원 어댑터를 빼고 배터리로 1시간쯤 되는 회의를 하나 녹음하고, 요약이 나올 때까지 그대로 둡니다. 노트북 화면은 꺼져도 됩니다.
3. 앱의 설정 > 일반 > "로그 폴더 열기"를 눌러 열린 폴더의 `app.log`를 보내 주세요.

## 바뀐 것

- **전사 속도 (Windows)**: flash attention을 켜고, 외장 GPU가 있으면 그것을 먼저 씁니다. Windows가 전사를 효율 코어로 옮겨 느리게 돌리지 않게(효율 모드) 합니다. 맥에서도 flash attention이 켜집니다.
- **처리 중 잠자기 방지**: 회의를 전사·요약하는 동안과 모델을 받는 동안 PC가 잠들지 않습니다. 화면은 꺼질 수 있습니다.
- **느린 이유 한 줄**: 처리가 느릴 만한 이유가 있으면 진행 표시 아래에 한 줄로 보입니다. 배터리의 에너지 절약 모드, GPU를 쓰지 못해 CPU로 처리 중, 이 PC에 쓸 수 있는 GPU가 없음, 전사가 회의 길이보다 오래 걸림 중 하나입니다.
- **모델 받기 속도**: 설정의 모델 행에 받는 속도와 이 파일의 남은 시간이, 홈과 요약 안내에 전체 남은 시간이 보입니다.
- **GPU 다시 시도**: 예전 버전에서 GPU 오류로 CPU 전사에 묶였던 PC는 1.0.3을 처음 켤 때 한 번 GPU를 다시 씁니다. GPU 전사가 비정상 종료하면 먼저 flash attention만 끄고 GPU로 다시 하며, 그래도 안 될 때 CPU로 넘어갑니다.
- **기록**: `app.log`에 전사 구간마다 처리 장치, GPU 이름, 걸린 시간, 전원 상태가 남고, 모델을 받은 속도도 남습니다.

## 알려진 제한

- Windows 10은 1809 이상이어야 앱이 열립니다.
- beam 크기와 스레드 수는 그대로입니다. 여러 PC에서 잰 뒤에 정합니다.
- Windows 설치 파일은 아직 실제 PC에 설치해 보지 않았습니다.
