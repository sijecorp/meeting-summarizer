녹음과 회의 문서를 세로로 긴 창에서 보고, 화면 몇 곳을 다듬은 버전입니다.

## 설치 파일

| 컴퓨터 | 파일 |
|---|---|
| Mac (Apple 실리콘: M1 이후, macOS 14.6 이상) | `meeting-summarizer_1.1.1_aarch64.dmg` |
| Windows 10(1809 이상)/11 (64비트) | `meeting-summarizer_1.1.1_x64-setup.exe` |

설치와 업데이트는 [설치 안내](https://github.com/sijecorp/meeting-summarizer/blob/master/docs/install.md)를 따릅니다. 이미 앞 버전을 쓰고 있으면 새 파일로 덮어 설치하면 되고, 회의 기록·설정·Slack 로그인은 그대로 남습니다. Mac은 새 버전도 처음 열 때 "그래도 열기"를 한 번 더 하고, 처음 Slack으로 보낼 때 키체인 접근을 물으면 Mac 로그인 암호를 넣고 "항상 허용"을 누릅니다.

## 바뀐 것

- **세로 창**: 녹음을 시작하거나 회의 문서를 열면 창이 세로로 긴 모양(520×880)으로 부드럽게 바뀝니다. 화상 회의 옆에 세워 두고 녹음과 요약을 보기 좋습니다. 홈이나 설정으로 가면 가로 창으로 돌아옵니다. 창 크기를 직접 바꾸면 가로·세로 모양마다 그 크기를 기억합니다. 화면이 작으면 그 안에 들어가게 줄입니다.
- **바로 바뀔 때**: 단축키(⌘R 등)로 화면을 바꾸거나 시스템의 동작 줄이기를 켜 두면 움직임 없이 바로 바뀝니다. 최대화나 전체 화면으로 쓰는 창은 크기를 바꾸지 않습니다.
- **녹음 화면**: 스크롤하지 않아도 한눈에 다 보입니다.
- **위쪽 헤더**: 트랙패드로 스크롤할 때 헤더가 끌려 내려가며 흔들리던 것이 없어졌습니다. 헤더는 늘 창 맨 위에 있습니다.
- **보내기 버튼**: 창이 좁고 채널 이름이 길면 보내기 버튼이 막대 밖으로 나가던 것을 고쳤습니다. 긴 채널 이름은 줄여 보이고 "으로 보내기"는 늘 보입니다.
- **첫 화면 문구**: "간단히 녹음하고, 요약해 보세요."로 바꿨습니다.
- 창을 520 폭까지 줄일 수 있습니다(전에는 720).

## 알려진 제한

- Windows 설치 파일은 아직 실제 PC에 설치해 보지 않았습니다. 창 모양이 바뀌는 움직임도 Windows에서는 아직 눈으로 확인하지 못했습니다.
- 1.1.0의 제한(베트남어·인도네시아어 회의의 이 PC 요약 품질, 한국어가 아닌 회의의 날짜 확인)은 그대로입니다.
