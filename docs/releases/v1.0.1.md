새 앱 아이콘을 입히고 첫 화면을 다듬은 버전입니다. 기능은 v1.0.0과 같습니다.

## 설치 파일

| 컴퓨터 | 파일 |
|---|---|
| Mac (Apple 실리콘: M1 이후, macOS 14.6 이상) | `meeting-summarizer_1.0.1_aarch64.dmg` |
| Windows 10/11 (64비트) | `meeting-summarizer_1.0.1_x64-setup.exe` |

설치와 업데이트는 [설치 안내](https://github.com/sijecorp/meeting-summarizer/blob/master/docs/install.md)를 따릅니다. 이미 v1.0.0을 쓰고 있으면 새 파일로 덮어 설치하면 되고, 회의 기록·설정·Slack 로그인은 그대로 남습니다. Mac은 새 버전도 처음 열 때 "그래도 열기"를 한 번 더 하고, 처음 Slack으로 보낼 때 키체인 접근을 물으면 Mac 로그인 암호를 넣고 "항상 허용"을 누릅니다.

## 바뀐 것

- **앱 아이콘**: 회사 로고의 `[ ]` 표시를 밝은 회색(`#D2D6D9`) 바탕에 올렸습니다. Dock, 작업 표시줄, 메뉴 막대·트레이, 설치 파일에 보입니다.
- **첫 화면**: 앱을 처음 열 때 보이는 화면에 스크롤이 생기지 않습니다. 창 크기를 바꾸면 그에 맞춰 가운데에 들어맞습니다.
- **창의 최소 크기**: 720×520에서 720×600으로 바꿨습니다. 첫 화면이 스크롤 없이 들어가는 가장 작은 크기입니다.

## 알려진 제한

v1.0.0과 같습니다. Windows 설치 파일은 아직 실제 PC에 설치해 보지 않았습니다.
