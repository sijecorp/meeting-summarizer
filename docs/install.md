# 설치 안내

회의를 녹음하고 요약해서 Slack으로 보내 주는 앱입니다. 설치는 5분이면 끝납니다.

## 설치 파일 받기

<OneDrive 링크>에서 내 컴퓨터에 맞는 파일 하나를 받습니다.

| 컴퓨터 | 파일 |
|---|---|
| Mac (Apple 실리콘: M1 이후, macOS 14.6 이상) | `meeting-summarizer_버전_aarch64.dmg` |
| Windows 10/11 (64비트) | `meeting-summarizer_버전_x64-setup.exe` |

Intel 칩 Mac은 지원하지 않습니다. Mac의 칩은 Apple 메뉴 > 이 Mac에 관하여에서 볼 수 있습니다.

앱은 처음 쓸 때 전사 모델과 요약 모델(합쳐 약 3.6 GB)을 받습니다. 받는 동안 디스크에 1 GB가 더 남아 있어야 하므로, 처음에는 약 4.6 GB의 빈 공간이 필요합니다. 모자라면 앱이 몇 GB가 더 필요한지 알려 줍니다.

## Mac

1. 받은 `.dmg` 파일을 엽니다.
2. 열린 창에서 앱 아이콘을 "응용 프로그램" 폴더로 끌어다 놓습니다.
3. 응용 프로그램 폴더에서 앱을 엽니다. 처음에는 "악성 코드가 없음을 확인할 수 없습니다"라는 경고가 뜨고 열리지 않습니다. "완료"를 누릅니다. "휴지통으로 이동"은 누르지 마세요.
4. Apple 메뉴 > 시스템 설정 > 개인정보 보호 및 보안으로 갑니다. 아래쪽 "보안" 부분에 있는 "그래도 열기"를 누르고, 다시 뜨는 창에서도 "그래도 열기"를 누른 뒤 Mac 로그인 암호를 넣습니다.
   - 이 버튼은 앱을 열려고 한 뒤 1시간쯤만 보입니다. 보이지 않으면 3번부터 다시 합니다.
   - 사내에서만 쓰는 앱이라 Apple의 검사를 받지 않아서 생기는 단계입니다. 처음 한 번만 하면 됩니다.
5. 처음 녹음을 시작하면 권한 요청이 두 번 뜹니다. 둘 다 "허용"을 누릅니다.
   - 마이크: 내 목소리를 녹음합니다.
   - 시스템 오디오 녹음: 화상 회의 상대방의 목소리를 녹음합니다.

실수로 "허용 안 함"을 눌렀다면 시스템 설정 > 개인정보 보호 및 보안에서 "마이크"와 "화면 및 시스템 오디오 녹음"에 들어가 meeting-summarizer를 켜고, 앱을 종료했다가 다시 엽니다.

앱을 종료하려면 화면 위쪽 메뉴 막대의 앱 아이콘을 누르고 "종료"를 고릅니다. 창을 닫으면 앱은 메뉴 막대에 남아 있습니다.

## Windows

1. 받은 `-setup.exe` 파일을 엽니다.
2. "Windows의 PC 보호" 창이 뜨면 "추가 정보"를 누르고 "실행"을 누릅니다. 사내에서만 쓰는 앱이라 뜨는 창입니다.
3. 설치 프로그램의 안내대로 "다음"과 "설치"를 누릅니다. 관리자 권한은 필요 없습니다. 내 계정에만 설치됩니다.
4. 설치가 끝나면 시작 메뉴에서 meeting-summarizer를 엽니다.

드물게 WebView2라는 구성 요소가 없는 PC에서는 설치 중에 이것을 함께 설치하며, 이때 관리자 암호를 물을 수 있습니다. 암호를 모르면 IT 담당자에게 요청하세요.

앱을 종료하려면 작업 표시줄 오른쪽 아래(숨겨진 아이콘 ^ 안에 있을 수 있습니다)의 앱 아이콘을 오른쪽 클릭하고 "종료"를 고릅니다. 창을 닫으면 앱은 그곳에 남아 있습니다.

## 새 버전으로 업데이트

앱이 스스로 업데이트하지 않습니다. 새 버전 소식이 오면 같은 링크에서 새 설치 파일을 받아 위와 같은 방법으로 설치합니다. 회의 기록과 설정은 그대로 남습니다.

녹음 중이거나 회의를 처리하는 중에는 업데이트하지 마세요. 먼저 앱을 종료합니다.

- **Mac**: 새 앱을 응용 프로그램 폴더로 끌어다 놓고 "대치"를 누릅니다. 새 버전도 처음 열 때 위 3~4번(그래도 열기)을 한 번 더 합니다.
- **Windows**: 새 `-setup.exe`를 실행하면 기존 버전 위에 설치됩니다.

요약 모델이 들어간 버전으로 업데이트하면 달라지는 점:

- 설정 > 요약(LLM)의 기본 LLM이 "선택 안 함"이면, 홈의 "모델 받기"가 전사 모델과 함께 요약 모델(2.7 GB)도 받습니다.
- 사내 미러는 `resolve/<커밋>/` 경로를 넘겨야 합니다. `resolve/main/`만 넘기던 미러에서는 새로 받는 모델이 받아지지 않습니다(아래 "관리자용: 모델 사내 미러").

**Mac에서 업데이트 뒤 소리가 녹음되지 않을 때**: Mac은 새 버전을 다른 앱으로 볼 수 있어서 권한을 다시 받아야 할 때가 있습니다.

1. 시스템 설정 > 개인정보 보호 및 보안 > 마이크에서 meeting-summarizer를 껐다가 다시 켭니다.
2. 같은 곳의 "화면 및 시스템 오디오 녹음"에서도 meeting-summarizer를 껐다가 다시 켭니다. 목록에서 골라 아래 "-" 버튼으로 지워도 됩니다. 그러면 다음 녹음 때 권한 요청이 다시 뜹니다.
3. 앱을 종료했다가 다시 엽니다.

## 지우기

- **Mac**: 앱을 종료하고, 응용 프로그램 폴더에서 meeting-summarizer를 휴지통으로 옮깁니다.
- **Windows**: 앱을 종료하고, 설정 > 앱 > 설치된 앱(Windows 10은 앱 및 기능)에서 meeting-summarizer를 찾아 "제거"를 누릅니다. 회의 기록까지 지우려면 제거 창에서 "애플리케이션 데이터 삭제하기"를 고릅니다.

앱만 지우면 회의 기록은 남아 있어서, 다시 설치하면 그대로 보입니다.

## 관리자용: 설치 파일 만들기

설치 파일은 GitHub Actions의 `build` 워크플로(`.github/workflows/build.yml`)가 만듭니다. Mac은 Apple Developer 계정 없이 임시 서명(ad-hoc)만 하므로 위의 "그래도 열기" 단계가 필요합니다.

1. 새 버전이면 먼저 `src-tauri/tauri.conf.json`의 `version`을 올려 master에 push합니다. 파일 이름에 이 버전이 들어갑니다.
2. 워크플로를 실행합니다. 둘 중 하나입니다.
   - 저장소의 Actions 탭 > 왼쪽 목록의 build > "Run workflow" > 브랜치 master > "Run workflow"
   - 버전 태그 push: `git tag v0.1.0 && git push origin v0.1.0`
3. 실행이 끝나면 그 실행 페이지 아래쪽 "Artifacts"에서 `meeting-summarizer-macos-arm64`와 `meeting-summarizer-windows-x64`를 받습니다. zip으로 받아지니 풀어서 `.dmg`와 `-setup.exe`를 꺼냅니다.
4. 두 파일을 OneDrive 공유 폴더에 올리고 동료들에게 링크와 이 문서를 알립니다.

- Artifacts는 30일 뒤 지워집니다. 받아 둘 파일은 그 전에 OneDrive에 올립니다.
- 비공개 저장소에서는 macOS 실행 시간이 10배로 계산됩니다. 배포할 때만 실행합니다.
- 실제 서명과 공증을 하려면 Apple Developer 계정을 만든 뒤 워크플로의 주석 처리된 `APPLE_*` 항목을 저장소 Secrets로 채우고 주석을 풉니다. 그러면 "그래도 열기" 단계와 업데이트 뒤 권한 문제가 없어집니다.

## 관리자용: 모델 사내 미러

앱은 모델 파일을 `https://huggingface.co`에서 받습니다. 사내망에서 닿지 않으면 사내 미러를 두고, 앱의 설정 > 전사 > "모델 다운로드 주소"를 미러 주소로 바꿉니다. 앱은 `{미러 주소}/{경로}`를 받으므로, 미러는 아래 경로를 그대로 넘겨야 합니다. 경로의 커밋은 고정이라 `resolve/main/`으로 바꾸면 안 됩니다.

| 파일 | 경로 | 크기(바이트) | sha256 |
|---|---|---|---|
| 전사 모델 | `ggerganov/whisper.cpp/resolve/5359861c739e955e79d9a303bcbc70fb988958b1/ggml-large-v3-turbo-q8_0.bin` | 874188075 | `317eb69c11673c9de1e1f0d459b253999804ec71ac4c23c17ecf5fbe24e259a1` |
| 음성 구간 감지(VAD) 모델 | `ggml-org/whisper-vad/resolve/9ffd54a1e1ee413ddf265af9913beaf518d1639b/ggml-silero-v6.2.0.bin` | 885098 | `2aa269b785eeb53a82983a20501ddf7c1d9c48e33ab63a41391ac6c9f7fb6987` |
| 요약 모델 | `unsloth/Qwen3.5-4B-GGUF/resolve/e87f176479d0855a907a41277aca2f8ee7a09523/Qwen3.5-4B-Q4_K_M.gguf` | 2740937888 | `00fe7986ff5f6b463e62455821146049db6f9313603938a70800d1fb69ef11a4` |

- 앱은 받기 전에 서버가 알려 준 전체 크기를 위 크기와 비교하고, 다르면 받지 않고 그 주소를 오류에 적습니다. 다 받은 뒤에는 sha256을 확인합니다.
- 미러가 `Range` 요청을 지원하면 끊긴 다운로드를 이어 받습니다.
- 설정에서 다른 전사 모델(`ggml-large-v3-turbo.bin`, `ggml-medium-q5_0.bin`)도 고를 수 있게 하려면 그 파일도 전사 모델 줄과 같은 커밋 경로로 넘깁니다.
